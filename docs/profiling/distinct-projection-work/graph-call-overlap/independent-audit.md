# 图级重叠独立核验

通过：9 条 DISTINCT、576 个图级调用，与 summary.json 的全部阶段字段精确一致。未调用或导入父分析器；独立解析整数纳秒时间，用排序区间合并计算 union，再枚举全部 endpoint 小区间、逐个判断哪些调用覆盖该区间，复算 occupancy 分布与积分。另直接求时长最长的两个调用交集。

每个调用 start/end 差、同线程同阶段无重叠、phase union、duration 总和、occupancy 积分、最长区间、两最长交集、线程调用数均一致；initial/provenance 互不重叠，二者 union 加 other 等于 outer，outer 加 untraced gap 等于 TSV。输入 JSON SHA256 与原收据一致。没有重新解码 JFR。
