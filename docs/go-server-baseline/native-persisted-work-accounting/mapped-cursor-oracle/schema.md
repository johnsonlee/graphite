# Storage-method capture schema

This is an actual pinned-main **storage-method** oracle, not public Cypher execution. The Java harness calls the private mapped-view loader through its actual preferred-view work-consumer interface, then copies the loaded view's immutable buffers, counts, StringTable and actual nodeOrder function into a separately constructed actual MappedCallSiteStringIndexView. It instruments the nodeOrder dependency to record calls; only explicitly marked negative-order controls replace one returned order with -1. No fixture bytes or main classes are rewritten.

The root object contains mainRevision, javaVersion, performanceMeasurements (0), actual loader callbacks, and 11 named cases with 19 ordered operations. Every operation records method/range inputs, callbackAction, preInterrupted, beforeCache, outcome/value or original exception class/message/stack, sameAsCallbackCause, ordered callback batch sizes, actual/returned nodeOrder reads, interruptedAfterMethod and afterCache. clearedForNextOperation is the result of Thread.interrupted() called **after recording** each operation, solely to isolate sequential harness controls. C10 intentionally runs binary search and validation together without that cleanup between calls.

Callback actions are none, interrupt (only sets the current thread flag), and throw (throws the same real CypherBudgetExceededException instance constructed for that operation). This does not impersonate an executor budget tracker or claim request diagnostics. Values include actual binary-search return, cursor construction, initial hasCurrent, ordered yielded node IDs/orders, and final cursor position. Cache snapshots reflect actual occupied slots, unsigned long keys and state bytes (1 valid, 2 invalid), count and closed status.

All posting IDs and normal node orders come from immutable actual-main writer archives. Controls on large use subranges at real absolute posting positions; their synthetic range/key selection is explicit and does not claim that a public query would select the subrange. Collision C09 uses actual hit64 property 0 row 0 and property 1 row 1, which collide at slot 0. Empty-range C11 is a method-level malformed/empty range control, not an asserted query route.

The first successful capture had 10 cases and 17 operations; it remains initial-capture with original inputs. Final captures add C11 and initialHasCurrent. Any comparison across that expansion must account for the declared schema change; final main/repeat compare every parsed field, including complete stacks. No P95 or performance claim follows from these synthetic fixtures.
