# Independent cursor-stage evidence audit

This audit reads existing evidence only. It starts no Go/JVM process and measures no performance. Run `python3 audit.py` from this directory to regenerate `audit.json`; the report binds every inspected artifact by SHA-256. External source snapshots and original capture directories are required.

The cursor-focused v1 failure is preserved: its only two failing tests are `TestMainMappedWarmCursorReadsEachOrderOnlyOnAdvance` and `TestMainMappedMatchingRetainedFallback`. Comparing every entry in both 2563-file source archives shows that v2 changed only the two corresponding test files, with no production changes. The first correction mutates the already loaded offset dependency under its lock, instead of writing a backing file that the reader had already copied. The second creates a genuine retained-builder fixture and chooses its corresponding route. These are explicit correctness-test controls, not production-data mutations or performance evidence. The v2 race-enabled focused run passes.

Probe v4 passes all four public oracle groups: 111 cases / 482 operations. Its complete source archive matches focused v2. The audit independently verifies archived logs against external originals, compressed and uncompressed hashes, every source-archive member against the frozen manifest, and the first failed run rather than discarding it.

The separate mapped-cursor oracle has 11 controls / 19 operations. Both final actual-main captures agree on every parsed field, including errors, stacks and callback/read order. All 45 copied artifacts match their external originals; all 34 fixture files match the unchanged before/after manifests. These are **storage-method controls**, including explicit negative-order dependency substitution, interruption/throwing callbacks and selected method ranges. They are not another public Cypher workload and are not included in the 111 public cases.

The independently repeated original main cold capture equals the frozen original across every parsed record: 1267 cases / 162304 graph-state observations, with no public or state differences. The runtime still exits 1 because the original all-success gate fails at case 821. The native full workload export is byte-identical to both original full exports; the fresh main capture is an array without the metadata wrapper, so its 1267 case definitions are compared as parsed values.

Both earlier native cold captures still have 15162 `mappedRangeCount` differences each, beginning at replay case 3, after execution, on `fixture-android-02` (main 7, Go 0). Their public outputs agree, but those runs used the previous source and do not validate the new cursor correction. Their error-class observer difference at case 821 also remains in the original comparison records. The repeated main evidence gives no reason to relax the state comparison or replace the reference.

The previous complete context/race/vet pass belongs to different source bytes and cannot certify this cursor source. The newly archived first cursor full check has context exit 0, race exit 1, and **no vet execution**. Its sole failing test has four subcases: `TestMainStringMappedColdWarmDemandAndCancellation`. Its archived observer counts calls whose `runtime.Caller` function name ends in `.ProjectionNodeOrder`; the new path records zero such calls, so the old cancellation trigger is not reached.

Focused v3 then passes with exactly one module-file change from v2: `internal/query/main_string_source_test.go`. Production bytes remain unchanged. The migrated test uses eight cold/warm controls for no cancellation, cancellation before construction, before the first row, and after the first row. It asserts actual cancellation, node IDs 2 and 41, validation-cache publication/preservation, and successful fresh-context reuse. This focused pass does not substitute for a subsequent complete context/race/vet pass. Probe v4 uses the preceding test version; its production source matches, but its entire source snapshot must not be described as identical to focused v3.

No overall acceptance is established. Required follow-up remains a complete full-check pass bound to the final source and a complete new-source real64 replay/state comparison. This audit establishes neither P95 performance, the unrelated three private event counters, JVM-qualified error classes/stacks in Go, nor a global memory reservation budget.
